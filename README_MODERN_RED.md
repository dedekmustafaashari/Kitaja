# PADANG EXPRESS Modern Red
Versi ini mempertahankan database jasa_kirim_amma dan CodeIgniter 4. UI diubah dari hijau menjadi merah, ditambah avatar kartun kurir, chat yang lebih aman/nyaman, fallback foto kurir, tombol pembatalan pelanggan, dan refresh status tracking.

Avatar default berada di public/uploads/couriers/kurir-pria.svg dan kurir-wanita.svg.
