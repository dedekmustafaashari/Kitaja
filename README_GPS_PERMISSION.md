# PADANG EXPRESS - GPS Permission
Jika Lokasi Saya tetap mengatakan akses ditolak:
1. Pastikan URL `http://localhost:8080`.
2. Klik ikon gembok/info di kiri URL -> Location/Lokasi -> Allow/Izinkan.
3. Refresh Ctrl+F5.
4. Windows Settings -> Privacy & security -> Location: Location services aktif.
5. Pada HP saat hosting, gunakan HTTPS dan izinkan lokasi browser.
Aplikasi tidak dapat memaksa browser melewati permission yang berstatus Denied. Versi ini menampilkan status permission dan mencoba fallback akurasi rendah bila high-accuracy GPS gagal.
