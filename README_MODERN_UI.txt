PADANG EXPRESS - MODERN UI
======================
Versi ini berasal dari project PADANG EXPRESS Gojek/Grab Style FIXED.
Fitur backend/database dipertahankan; UI diperbarui agar lebih modern dan mobile-friendly.

Database: jasa_kirim_amma
Run:
1. Extract ke C:\xampp\htdocs\AMMA_KIRIM
2. Buka folder AMMA_KIRIM di VS Code
3. Pastikan Apache + MySQL aktif
4. Import database.sql (jika belum)
5. Terminal: php spark serve
6. Buka http://localhost:8080
